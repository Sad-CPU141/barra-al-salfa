# Barra Al-Salfa · برا السالفة

Everyone knows the secret word except one. Find the outsider before they figure it out.

**Status: coming soon.** For now this repo just holds the "coming soon" start page.

Live: https://sad-cpu141.github.io/barra-al-salfa/ · Part of [Game Night](https://sad-cpu141.github.io/).

## How it'll work

1. Pass the phone. Each player privately sees the secret word, or "You're out of the loop!"
2. Take turns asking each other questions about the word.
3. Vote on who the outsider is.
4. A caught outsider can still win by guessing the word.

Planned: 4–12 players on one phone, Arabic and English word packs, two outsiders for big groups, a round timer, and scoring across rounds.
